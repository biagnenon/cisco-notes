## Notes

### Wireless Network

Our smartphones can connect on different networks (wi-fi, bluetooth, cellular) and can do so simultaneously.
Cell phones contains multiple radios, transmitters and receivers that we can use to talk. They use the data plan network, using the cell phone infrastructure to access the internet. They can also use location services through GPS.

In addition to GSM (Global System for Mobile Communication - a second generation digital cellular network ) and 4G/5G (also belong to digital cellular network) transmitters and receivers, smartphones make connections in a variety of ways :
- ***GPS (Global Positioning System) |*** uses satellites to transmit signal used by devices to calculate their location. Positioning accuracy is within 10 meters.
- ***Wi-Fi |*** transmitters and receivers enable the phone to connect to local networks and the internet as long as in range of the signal from a wireless access point. Usually private, often provided as guest or public access hotspots. A hotspot is an area where Wi-Fi signals are available.
- ***Bluetooth |*** a low power, shorter range technology that is intended to replace wired connectivity for accessories such as speakers, headphones and microphones. It can be used to transmit both data and voice. It can connect to multiple devices simultaneously. The connection process is called pairing, and both devices need to be discoverable.
- ***NFC (Near Field Communication) |***  a wireless communication technology that enables data to be exchanged by devices that are in very close proximity to each other, usually less than a few centimeters. it uses electromagnetic fields to transmit data

Using bluetooth a mobile device can connect to another device to share a network connection in a process called ***Tethering***. it can also be performed with a Wi-Fi connection or a cable connection such as USB.


### Mobile Device Connectivity

Precautions to take to protect Wi-Fi communications on mobile devices :
- Never send login or password information using unencrypted text (plaintext).
- Use a VPN connection when possible when sending sensitive data.
- Enable security on home networks.
- Use WPA2 or higher encryption for security.

If a device does not prompt to connect to a Wi-Fi network, its SSID(Service Set Identifier) broadcast may be turned off or the device may not be set to connect automatically. SSID is the name assigned to a wireless network.
